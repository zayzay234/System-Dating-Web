# PluralMatch — VS Code Website

A front-end prototype for a plural-friendly dating / connection website.

## Run it

1. Open this folder in VS Code.
2. Open `index.html`.
3. Either use VS Code's Live Server extension, or double-click `index.html`.
4. No build tools are required.

## Files

- `index.html` — page structure
- `style.css` — gothic responsive styling
- `script.js` — demo profiles, filters, likes, profile modal and info modal

## Turning it into a real website

This is intentionally a front-end demo. For a real service you would need:
- authentication and age verification
- a secure database
- server-side validation
- profile/photo upload storage
- block/report/moderation systems
- privacy controls and account deletion
- consent-aware matching and messaging
- rate limiting and abuse prevention
- HTTPS and secure session handling
- a clear privacy policy and terms

Do not store sensitive mental-health or system information unless it is genuinely necessary and users have clearly consented to its collection and use.
